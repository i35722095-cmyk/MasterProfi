# Установка MasterProfi AI Agent на чистый Mac

Эта инструкция разворачивает агента на новом Mac с нуля. В конце он будет ждать ТЗ в папке `input/` и создавать отдельную папку с результатом для каждого запуска обработки в `output/`.

## Что потребуется

- Mac с macOS Sonoma 14 или новее. На Mac с Apple Silicon Ollama использует CPU и GPU; на Intel — только CPU. См. [официальные требования Ollama](https://docs.ollama.com/macos).
- Права на установку программ на компьютере.
- Доступ в интернет только на этапе установки Python-библиотек и модели Qwen.
- Приватная копия локального прайса и, при необходимости, примеров ТЗ/КП. Эти коммерческие файлы не хранятся в Git.

## 1. Проверить инструменты

Откройте приложение **Терминал** и выполните:

```bash
git --version
python3 --version
```

Если обе команды отработали, ничего устанавливать не нужно. Подходит Python 3.9 и новее.

Если не найдена команда `git`, установите инструменты разработчика Apple:

```bash
xcode-select --install
```

Если не найдена команда `python3`, установите актуальный Python с [python.org](https://www.python.org/downloads/macos/) и откройте новый Терминал.

## 2. Установить Ollama и модель

Скачайте приложение для macOS с [официальной страницы Ollama](https://ollama.com/download), перенесите его в `Applications` и запустите один раз.

Затем в Терминале выполните:

```bash
ollama --version
ollama pull qwen3.5:9b
ollama list
```

Последняя команда должна показать `qwen3.5:9b`. Имя модели должно совпадать со значением `model` в `config/llm.toml`.

## 3. Скачать код агента

В Терминале:

```bash
mkdir -p ~/AI-Agents
git clone https://github.com/VDevGushin/MasterProfi.git ~/AI-Agents/Ivan-Work
cd ~/AI-Agents/Ivan-Work
```

Если репозиторий закрытый, сначала войдите в GitHub через Fork или настройте доступ по SSH.

## 4. Создать Python-окружение и установить библиотеки

В папке проекта выполните:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Папка `.venv/` создаётся только на этом компьютере. Её не нужно копировать, отправлять в Git или редактировать.

## 5. Добавить локальные данные

В Git намеренно нет клиентских и коммерческих файлов. С защищённого носителя или старого компьютера скопируйте в проект:

```text
Локальные данные/  — актуальный XLSX-прайс (обязательно для расчёта)
ПримерыТЗ/         — примеры входных ТЗ (желательно: нужны для тестов и RAG)
ПримерыКП/         — старые КП (желательно: нужны для RAG и сверки)
```

Папки `input/` и `output/` уже есть. В `input/` кладут новые ТЗ, а `output/` агент заполняет сам: для каждого запуска создаётся отдельная папка результата с датой, названием ТЗ и идентификатором.

## 6. Настроить агента

Все настройки находятся в папке `config/`:

- `config/agent.toml` — курс, гарантия, срок изготовления;
- `config/llm.toml` — провайдер, имя модели и лимиты LLM;
- `config/competitors.toml` — подтверждённые аналоги тканей конкурентов;
- `config/competitor_sources.toml` — справочные сайты конкурентов.

Не меняйте названия полей слева от `=`. Подробности — в `config/README.md`.

## 7. Проверить установку

Если скопированы прайс и все примеры, выполните:

```bash
.venv/bin/python -m source.tests.test_agent
```

Ожидаемый результат:

```text
OK
```

Если примеров ещё нет, этот тест пропустите: для рабочего расчёта достаточно локального прайса.

## 8. Запустить агента

В папке проекта:

```bash
./run_agent.command
```

Должно появиться сообщение:

```text
Агент запущен. Ожидаю XLSX, DOCX, PDF или TXT в папке input.
```

Дальше:

1. Положите ТЗ формата XLSX, DOCX, PDF или TXT в `input/`.
2. Следите за ходом расчёта в Терминале.
3. Откройте самую новую папку с датой и названием ТЗ в `output/`.
4. Если внутри находится PDF-КП — расчёт завершён; его можно передавать клиенту. Агент удалит исходное ТЗ из `input/` только после успешной проверки КП.
5. Если вместо PDF появился `Требуется_уточнение.txt`, откройте его: там простыми словами указана проблемная позиция и нужное решение. Исходное ТЗ остаётся в `input/`; после уточнения правила расчёта запустите агента повторно.

Файл `Требуется_уточнение.json` в этой же папке — технические данные для специалиста. Менеджеру не нужно его открывать или редактировать.

Остановить агента: `Ctrl + C`.

## Частые проблемы

| Сообщение | Что сделать |
| --- | --- |
| `zsh: command not found: ./run_agent.command` | Перейдите в папку проекта командой `cd ~/AI-Agents/Ivan-Work` и снова выполните `./run_agent.command`. |
| `permission denied` | Один раз выполните `chmod +x run_agent.command`. |
| `ModuleNotFoundError` | Выполните `.venv/bin/python -m pip install -r requirements.txt`. |
| `ollama: command not found` | Запустите приложение Ollama, затем откройте новый Терминал. Если не помогло — переустановите Ollama с официального сайта. |
| Агент не может связаться с Qwen | Проверьте `ollama list`, запустите Ollama и убедитесь, что имя модели в `config/llm.toml` совпадает с установленным. |
| Нет XLSX-прайса | Скопируйте актуальный файл прайса в `Локальные данные/`. |

## Обновление кода

Перед обновлением остановите агента (`Ctrl + C`). Затем в папке проекта:

```bash
git switch master
git pull
.venv/bin/python -m pip install -r requirements.txt
```

Не удаляйте папки `Локальные данные/`, `ПримерыТЗ/`, `ПримерыКП/`, `input/` и `output/`: они не обновляются из Git и содержат локальные данные.
